```go
type Image struct{ Label string; JPEG []byte }
type JSONRequest struct{ System, Prompt string; Images []Image; Schema map[string]any; MaxOutputTokens int }
type JSONResponse struct{ Text string; InputTokens, OutputTokens int }
type Provider interface {
    Name() string
    GenerateJSON(ctx context.Context, req JSONRequest) (JSONResponse, error)
    SupportsImages() bool
    Ping(ctx context.Context) error // cheap auth/model check, no generation (used by doctor)
}
func EstimateTokens(req JSONRequest) int // ceil(len(System+Prompt)/4) + 260*len(Images) + MaxOutputTokens
func NewGemini(apiKey, model string, timeout time.Duration) (Provider, error)  // google.golang.org/genai; ResponseMIMEType "application/json" + ResponseJsonSchema

type Guarded struct{ Primary, Fallback Provider; Limiter pipeline.Limiter; Faults pipeline.Faults; On429 func(context.Context) }
func (g *Guarded) GenerateJSON(ctx context.Context, req JSONRequest) (JSONResponse, error) // implements Provider
func FromConfig(cfg config.Worker, lim pipeline.Limiter, f pipeline.Faults, on429 func(context.Context)) (text Provider, vision Provider, err error)
```
Error mapping in every adapter: HTTP 429 / `RESOURCE_EXHAUSTED` → `&RateLimitedError{"llm", retryAfter parsed from Retry-After or RetryInfo, default 30s}` and call `On429`; 5xx / timeout / connection → `&RetryableError{"LLM_UNAVAILABLE"}`; 400 invalid model, 401, 403 → `&FatalError{"LLM_CONFIG_ERROR"}`.
`Guarded.GenerateJSON`: `Faults.Check(FaultLLM)` → `Acquire(BucketLLMRequests,1)` → `Acquire(BucketLLMTokens, EstimateTokens(req))` → `Acquire(BucketLLMDaily,1)` → Primary. (Changed in Z2: the daily bucket is taken last, so a per-minute wait that ends in a rate-limit retry doesn't spend a daily unit.) If Primary returns `RetryableError{LLM_UNAVAILABLE}` twice in a row for this call and `Fallback != nil` → `Acquire(BucketLLMFallbackRequests,1)` → Fallback once. 429s never trigger fallback (FR-LLM-3).

**Notes from Track A (read before starting):**
- The token bucket can never hold more than its capacity: `LLM_TPM/6` tokens, which is 33 333 at the default `LLM_TPM=200000`. The Redis script caps any request at that capacity, so `Acquire(BucketLLMTokens, n)` with `n` above capacity silently takes only `capacity` tokens and under-counts. In `Guarded`, if `EstimateTokens(req)` is larger than `cfg.LLMTPM/6`, acquire it in chunks of at most that size, one after another. `FromConfig` can pass the chunk size into `Guarded`; a zero chunk size means a single `Acquire`. Add a test `TestGuardedSplitsLargeTokenEstimate` with a recording limiter.
- `On429` should be wired to `func(ctx) { ratelimit.Incr429(ctx, rdb) }` in `cmd/worker/main.go` during Z1. Don't import `internal/ratelimit` from `internal/llm`.
- Faults: `Faults.Check(ctx, pipeline.FaultLLM)` returns the injected `*pipeline.RateLimitedError`. Return it as-is.
